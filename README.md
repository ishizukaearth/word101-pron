word101の第1段階　TTSのモデル音と自身の声を比較するため、モデル音と自身の声を揃えて切り出す。
V15で一応安定した結果が得られたがV18は切り出し条件を整理したバージョン。
レビュー用に吐き出したJSONファイルにはもとになるdemo_all,user_allと切り出したdemo_voiceとuser_voiceが格納されており、vewer.htmlで内容をレビューできる
TTSのモデル音、ユーザの声はデータを20ms窓で監視して、開始条件・終了条件を満足した段階で発話音を切り出し記録
波形およびスペクトラムを横（時間）縦（音量・周波数）を正規化してグラフに表示する。
また、ブラウザの音声認識を有効にすれば、ユーザ音を認識した候補語５つとそれぞれの確信度を取得し、当該後が候補語に含まれていれば合格として確信度を表示する。
V18では、ピークRMSのX1(10)%を越えた時点で有音判定を行い、立ち上がり時間X3(30)ms戻った時点を発話開始
発話終了は、雑音レベル以下がX2(200：語中の無音区間より長い時間）ms続いた時点で終了判定を行い、そのX2ms前で打ち切る
